  • 2026 · 第一次对接大模型出图

    文字生成图片

    用 OpenRouter 的 OpenAI 兼容接口接上了 gpt-5.4-image-2 模型，实现「输入文字出图片」。学会了把密钥放进环境变量、处理 base64 图片数据、设置长超时，也第一次遇到 API 的地理限制——原来接口报错本身也是要读懂的信息。

  • 2026 · 第一个全栈功能

    一键去除图片背景

    第一次写后端：用 Node.js + Express 搭了一个接口，把图片上传给 Replicate 上的 remove-bg 模型，再把抠好的图返回给页面。学会了前后端分工、文件上传、环境变量保护密钥，也第一次用上了拖拽上传和结果下载。

  • 2026 · 第一次 API 调用

    第一次 API 调用

    第一次调用网络 API：用 fetch 请求 Open-Meteo 的天气接口，拿到了北京的实时气温和天气状况。不需要 API Key 就能获取真实数据，感觉打开了一扇新的大门。

  • 2026 · 第一个个人网页
